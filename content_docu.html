Documentation

General Documentation

At this place, we provide some pdf documents describing the usage of Secondo in general. Furthermore, some examples are shown, how to use Secondo. If you want to retrace these examples, install Secondo. How to do this, can be read here.

Note that starting with version 4.0.0, Secondo is natively capable of distributed query processing (running Secondo on many computers / multiple cores). This is explained in the second document.

  • User Manual (Version 4.2, November 2019)
  • Tutorial: Distributed Query Processing in Secondo (Version 4.0, October 29, 2019)
  • Example: Parallel Trajectory Management in Secondo (Version 1.1, January 3, 2020)
  • Installation Instructions for Parallel Trajectory Management in Secondo (Version 1.0, October 30, 2019)
  • Example: Loading Tracks and Displaying Them With a Map Background
  • Integrating Programs and Documentation / The PD system
